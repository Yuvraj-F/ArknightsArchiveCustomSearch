# Custom Search For the Arknights Archive on Tumblr
This search is made specifically for the Arknights Archive blog on Tumblr to give users easy access to normal search and searching using tags. 

## ThemeWithCustomSearch.html
This file is a copy of the original theme used for the blog taken from [olleotathemes.tumblr.com](https://olleotathemes.tumblr.com/theme/impress) with the custom search code added to this theme.

## customSearchSnippet.html
This file contains the entirety of the custom search code by itself.
